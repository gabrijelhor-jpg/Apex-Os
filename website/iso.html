Apex OS
Početna Instalacija

Što je ISO?

ISO je jedna velika datoteka (npr. 4 GB) u kojoj je spremljen cijeli Apex OS, kao instalacijski DVD — samo kao datoteka na disku.

Zašto ti treba?

Bez ISO-a ne možeš Apex staviti na USB i instalirati na laptop. To je kao Windows instalacijski USB — samo za Apex.

Kako doći do ISO-a?

Najlakše na Windowsu: uploadaj projekt na GitHub i neka se ISO izgradi automatski (oko 1 sat).

  1. Napravi račun na github.com
  2. Uploadaj mapu Apex (GitHub Desktop je najlakši)
  3. Actions → Build Apex ISO → Run workflow
  4. Preuzmi gotov ISO iz Artifacts

Ne vidiš „Build Apex ISO”? Uploadaj skrivenu mapu .github. Na PC-u pokreni napravi-zip-za-github.ps1 ili pročitaj docs/NEMA-BUILD-APEX-ISO.md.

Detaljno: docs/GITHUB-ISO.md

Kad imaš ISO

  1. Preuzmi datoteku apexos-....iso
  2. Rufus → zapiši na USB
  3. Slijedi upute za instalaciju
