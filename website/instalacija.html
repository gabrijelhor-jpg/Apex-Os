Instalacija Apex OS na laptop

Korak-po-korak vodič za Windows laptop. Procijenjeno vrijeme: 30–60 minuta.

1. Priprema

  • USB 8 GB+ (bit će obrisan)
  • ISO datoteka Apex OS-a
  • Rufus ili Etcher
  • Backup važnih datoteka ako brišeš Windows

2. Preuzmi ISO

Na početnoj stranici klikni Preuzmi ISO. Ako piše da ISO nije dostupan, prvo ga moraš izgraditi (developer) ili pričekati objavu na serveru.

Stranica ne radi lokalno? U mapi website pokreni:

python -m http.server 8080

Zatim otvori http://localhost:8080

3. Zapiši ISO na USB (Rufus)

  1. Umetni USB
  2. Rufus → Select → tvoj apexos-....iso
  3. Scheme: GPT (noviji laptopi) ili MBR (stariji)
  4. START

4. Boot s USB-a

  1. Restart laptopa s umetnutim USB-om
  2. Pritisni F12, F2, Esc ili Del (ovisno o modelu)
  3. Odaberi USB / UEFI boot
  4. Ako ne radi: u BIOS isključi Secure Boot i Fast Boot

5. Instaliraj na disk

  1. U live Apex OS-u spoji Wi‑Fi
  2. Na radnoj površini klikni Instaliraj Apex OS
  3. Odaberi jezik, particije, korisničko ime i lozinku
  4. Čekaj kraj instalacije → Restart → izvadi USB

6. Nakon instalacije

  • Google — preglednik (Chromium) s Google stranicom
  • Apex Store — instaliraj Discord, Steam, dodatne aplikacije (treba internet)
